# AND101 Project 4 - CodeMath

Submitted by: **Seth Servin**

Time spent: 2 hours spent in total

## Summary

**TippingCalculator** is an Android app that calculates a tip based on the user's bill amount and selected tip percentage. The app also allows the user to enter the number of people in their party and calculates how much each person should pay.

If I had to describe this project in three (3) emojis, they would be: 💵 🧮 🍽️

## Application Features

The following REQUIRED features are completed:

- [x] At least one (1) user input
- [x] At least one (1) interactive View
- [x] At least one (1) output of a calculation based on the user input

The following STRETCH features are implemented:

- [x] Implement ViewBinding to reduce boilerplate code and increase efficiency
- [x] Add at least one (1) additional functionality

The following EXTRA features are implemented:

- [x] Added a party size input that splits the total bill between multiple people
- [x] Added a tip percentage slider
- [x] Automatically updates the tip, total, and per-person amount when the user's input changes
